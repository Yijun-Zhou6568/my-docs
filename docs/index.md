# 我的技术文档

欢迎访问我的个人文档网站。本网站使用 MkDocs 构建，通过 GitHub Actions 自动部署到 GitHub Pages。

- 作者：Yijun-Zhou6568
- 实践主题：静态文档自动部署
- [关于本项目](about.md)
- [使用指南](guide.md)
- [API 参考](api.md)

## 这个网站是什么

这是开源软件课程实践项目 2 的成果。仓库里只有 Markdown 源码、一个 `mkdocs.yml` 配置和一条 GitHub Actions 工作流，网站的 HTML 由机器在云端生成，我本人不碰任何网页文件。

## 网站内容一览

| 页面 | 内容 | 维护方式 |
| --- | --- | --- |
| 首页（本页） | 网站说明与导航入口 | 修改 `docs/index.md` |
| 关于 | 项目目标与技术组成 | 修改 `docs/about.md` |
| 使用指南 | 修改、预览、发布的完整流程 | 修改 `docs/guide.md` |
| API 参考 | 示例接口的请求与返回说明 | 修改 `docs/api.md` |

## 我最想记住的一句话

文档写作最怕的不是写不出来，而是写完之后没人知道最新版在哪里。把这套“推送即发布”的流程跑通以后，仓库里的 Markdown 就是唯一正确的版本，网站的更新不再依赖我记得去手动上传。
