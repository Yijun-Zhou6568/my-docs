# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| page | query | integer | 否 | 页码，默认 1 |
| size | query | integer | 否 | 每页条数，默认 10，最大 50 |
| keyword | query | string | 否 | 按标题模糊匹配 |

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

### 返回字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | integer | 文档唯一编号 |
| title | string | 文档标题 |

### 错误码

| 状态码 | 含义 | 处理建议 |
| --- | --- | --- |
| 400 | 参数格式错误 | 检查 `size` 是否超过 50 |
| 404 | 文档不存在 | 确认文档编号 |
| 429 | 请求频率过高 | 降低调用频率后重试 |

## 设计说明

这里只写了两个字段，是因为这份文档的目的不是描述真实接口，而是练习把“请求方法、请求路径、参数表、返回示例、错误码”写清楚。把这五样写全，看文档的人才不用反复回头问人。
